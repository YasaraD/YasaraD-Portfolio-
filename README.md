## 🛠️ How to Run Locally

### 1. Development Mode
Run the development server with hot-reload:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Production Build
Create an optimized production build:
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```
